# Claude Suggestion Tool

A small Chrome extension that adds a 💡 button to the claude.ai composer. Click it and you get three possible next messages based on your conversation so far. Click one and it drops into the input box, ready to send or edit.

I built this because I kept staring at an empty box, unsure how to push a conversation further. Sometimes I want a follow-up question I hadn't thought of, or a different angle on what I just asked. This gives me a starting point without much effort.

## Features

- **One-click suggestions.** A 💡 button sits next to the other composer controls. Click it and the extension reads the current conversation and asks for three suggested messages.
- **Replace or review.** Clicking a suggestion replaces whatever is in the input box. Nothing is sent automatically, so you can read it, tweak it, or just hit enter.
- **Refresh when you want something different.** The ↻ button in the corner of the list requests a new set.
- **Keyboard friendly.** Press `1`, `2`, or `3` to pick a suggestion. Use the arrow keys to move through the list, and `Esc` to close it. When you open the list from the keyboard, the first item is focused automatically.
- **Closes out of the way.** Clicking outside the box or pressing `Esc` dismisses it. Opening it again while it's already visible also closes it.
- **Loading and error states.** While suggestions are being fetched, you'll see a shimmer placeholder. If something goes wrong, you get a short message and a "Try again" button instead of a blank box.

## How to Use It

1. Open [claude.ai](https://claude.ai) and start a conversation, or open an existing one.
2. Optionally type a draft in the input box. The extension uses your draft as part of the context.
3. Click the 💡 button in the composer.
4. Pick a suggestion by clicking it or pressing its number.
5. Edit the text if you want, then send it.

## Installing Locally

The extension isn't on the Chrome Web Store, so you'll load it manually. It takes about a minute.

### Requirements

- Google Chrome or any Chromium-based browser (Edge, Brave, Arc, etc.)
- A copy of this project folder on your computer

### Steps

1. **Get the files.** Clone the repo or download it as a ZIP and unzip it. The folder should contain at least these two files:

   ````
   claude-suggestion-tool/
   ├── manifest.json
   └── content.js
   ````

   Both files need to be in the same folder.

2. **Open the extensions page.** In Chrome, go to `chrome://extensions` in the address bar.

3. **Turn on Developer mode.** Use the toggle in the top-right corner of the extensions page.

4. **Load the extension.** Click **Load unpacked**, then select the folder that contains `manifest.json`. Don't select the individual file.

5. **Check that it's enabled.** You should see "Claude Suggestion Tool" in your list of extensions with the toggle switched on.

6. **Try it out.** If claude.ai was already open, reload the tab. Then look for the 💡 button in the composer.

### Updating After Changes

If you pull new changes or edit `content.js` yourself:

1. Go back to `chrome://extensions`.
2. Click the reload icon (↻) on the Claude Suggestion Tool card.
3. Reload any open claude.ai tabs.

Chrome doesn't pick up changes to content scripts until the extension is reloaded and the page is refreshed.

### Troubleshooting

- **The 💡 button doesn't appear.** Make sure you're on `https://claude.ai/`, not a subdomain or a different site. Reload the page after installing. If claude.ai has recently updated its interface, the extension may need an update to find the composer again.
- **"Couldn't load suggestions" keeps showing up.** The backend may be down or unreachable from your network. Open the browser console (F12) and look for a "Suggestion fetch failed" message to see the status code.
- **Suggestions don't replace my draft.** Click inside the input box once before choosing a suggestion, then try again. Some browser states can block the text insertion if the editor doesn't have focus.

## Limitations

- It only works on claude.ai. It won't run on other sites.
- Suggestions are generated by a model, so they aren't always useful. Treat them as a starting point, not a finished message.
